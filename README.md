# Fork of The Parity Public License

This was born since I don't like permissive MIT-like licenses.

The main difference between the original [Parity](https://github.com/licensezero/parity-public-license) and the forked version is a "Contribute" part.

The fork version restricts contributing to only two licenses, this one and [AGPLv3.0](https://www.gnu.org/licenses/agpl-3.0.en.html).

That's it.
